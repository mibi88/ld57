                             GOLD HUNGER
                              by Mibi88

My game for the Ludum Dare 57 (jam category). it uses my new game engine
MibiEngine2 (if it can be called a game engine, it's far from being finished).

I'm unhappy with what I got done this week end... My neural network idea is way
cooler, but i was scared that it would be too complicated for the two days I
have... My game didn't turned out so well, and it feels more like a regression
than an amelioration... Even if Antwars also kinda sucked, it was quite
polished for a game made in two days...

I'm still posting this game, and expecting honest and constructive feedback.
After all, it was probably a very helpfull lesson to code this game: I should
have gone, as for the LD55 and LD56 with an ambitious idea, it may have also
sucked, but it probably couldn't have been that worse!

My game engine also wasn't ready at all, I hope that in october, for the LD58
it will be ready! I found quite a lot of bugs with it while coding this game,
which slowed me down. I think I would have been better off if I wrote
everything from scratch, but it is not that cool, and it gave me the occasion
to try and make a game (finally) with my engine, if it can even be called an
engine.

I've recorded everything so I'll make a timelapse soon, and I'm planning to
make a web (and/or maybe a windows) version soon, my engine currently only
works on linux.

    BRAINSTORMING

 - Platformer on multiple layers, which do not scroll at the same speed
   (parallax scrolling), and you need to switch from one layer to another to
   complete the level.
 - A game about the digging of the biggest hole in the world by the USA and the
   soviet union who challenged each other IIRC, where you are digging deeper
   and deeper and need to block lava etc. as quickly as possible. When you went
   so far that you're near the center of the earth you have to fight a big
   boss who is spreading lava, which you need to block.
 - Something about color depth
 - You need to change numbers to get the correct result at the end of multiple
   levels of a neural networks (the layers are the depth thing).
 - Or you need to change the values of th neurones in the network to get the
   expected result.
 - You're digging in a mine and need to find gold (or other resources) quickly
   or you die. With these resources you can get powerups etc.
 - You need to dig a hole deeper and deeper but if you're not finding any
   resources you loose. When you dug deep enough you fight a big boss. You can
   buy upgrades in a shop. A timer encourages speedrunning.
